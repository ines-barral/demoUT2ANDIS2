CASOS DE PRUEBA - POST /paquetes
==================================
Límites vigentes según .env:
  normal: peso_kg<=5, alto_cm<=60, ancho_cm<=60, largo_cm<=80
  fragil: peso_kg<=8, alto_cm<=40, ancho_cm<=40, largo_cm<=50

Cada caso incluye el JSON de entrada y el resultado esperado.

##################################################################

CASO 1 - normal VALIDO (todo dentro de limites)
------------------------------------------------------------------
{
  "tipo_paquete": "normal",
  "peso_kg": 3,
  "alto_cm": 50,
  "ancho_cm": 50,
  "largo_cm": 70
}

Esperado: 200 -> {"estado": "aceptado", ...}

##################################################################

CASO 2 - normal INVALIDO - excede peso (6 > 5)
------------------------------------------------------------------
{
  "tipo_paquete": "normal",
  "peso_kg": 6,
  "alto_cm": 50,
  "ancho_cm": 50,
  "largo_cm": 70
}

Esperado: 422 -> motivo: peso_kg excede el maximo permitido (5) para tipo 'normal'
